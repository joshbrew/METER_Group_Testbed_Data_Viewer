Just double-click the .html file to run it in browser.

Made this to help TAHMO (Trans-African Hydro-Meteorological Survey) more quickly analyze dozens of devices on a testbed to see which devices were failing for what reasons. Zentra Cloud is too slow for this, so this tool made it a lot easier.

Download CSV .zips for your ATMOS or TEROS (etc) logs off of your ZL6 or EM60s on Zentra Cloud. Load them into this .html individually or as a combined .zip, export the populated file if needed.

Includes my `uplot-webgpu` library and some other optimizations for viewing lots and lots of data points without slowdown. Your browser should be up-to-date to run this properly.
